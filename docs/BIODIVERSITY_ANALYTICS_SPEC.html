1. Why Traditional Pipelines Fail & How We Improve Them

Current Limitations of Traditional Pipelines

⚠️ Uncalibrated Overconfidence

Traditional taxonomic classifiers (naive BLAST, RDP, flat multiclass) assume every environmental sequence already exists in the reference library (closed-world assumption).

When encountering rare, unsequenced, or dark taxa, they force assignment to the nearest neighbor with falsely elevated confidence scores.

🚫 All-or-Nothing Bottleneck

Pipelines use rigid similarity thresholds (e.g. 97%). Sequences failing the threshold are discarded as "unassigned".

This throws away evolutionary conservation that could reliably pinpoint family or genus ancestry.

📊 No Community Synthesis

Workflows stop at flat sequence tables. They don't compute whether an ecosystem is balanced, collapsing, or dominated by invasive blooms.

Requires cumbersome manual export into external R software (vegan, phyloseq).

🧬 Biomass Conflation

Raw read counts are conflated with organism biomass, ignoring gene copy number variance, shedding rate differences, and PCR amplification skew.

Our Improved Approach

🌲 Graceful Hierarchical Back-Off

Evaluates confidence dynamically across the full Linnaean hierarchy:

Domain → Phylum → Class → Order → Family → Genus → Species

If species confidence is insufficient, it automatically steps back to the deepest ancestral rank that is mathematically validated.

🔍 Novelty & "Dark Taxa" Isolation

Isolates high-uncertainty embeddings that fall outside known reference clusters. Flags them as Candidate Novel Lineages without distorting known biodiversity metrics.

⚡ Automated Ecological Engine

Transforms classified ASV counts with noise suppression, normalizes to relative abundance vectors on the probability simplex, and automates alpha/beta diversity computation.

🛡️ Substrate-Aware Guardrails

Accounts for environmental transport dynamics:

  • Aquatic: Tidal/river drift warnings (regional presence vs. pinpoint spot).
  • Soil: Mineral-bound relic DNA persistence indicators.

Phase 1: Data Filtering & Relative Abundance Transformation

Raw sequencing libraries contain low-abundance stochastic artifacts, index hoppers, and primer dimers. Before community metrics are derived, reads must undergo noise suppression and simplex normalization.

1. Low-Abundance Noise Thresholding

$$\tilde{n}_i = \begin{cases} n_i & \text{if } \frac{n_i}{N} \ge \tau \\ 0 & \text{if } \frac{n_i}{N} < \tau \end{cases}$$
  • $n_i$: Raw sequence read count assigned to taxon/ASV $i$.
  • $N = \sum_{k=1}^M n_k$: Total sequencing depth of the sample.
  • $\tau$: Noise-floor filter threshold (default: $\tau = 0.001$, or $0.1\%$).

2. Relative Abundance Normalization ($p_i$)

$$p_i = \frac{\tilde{n}_i}{\sum_{k=1}^{S} \tilde{n}_k}$$
  • $p_i$: Proportion of sequencing reads attributed to taxon $i$.
  • $S$: Total number of distinct taxa with non-zero counts remaining post-filter.
  • Satisfies the unit probability simplex condition: $\sum_{i=1}^S p_i = 1.0$, with $p_i > 0$.

Phase 2: Alpha-Diversity Formulations

Alpha diversity quantifies biological variety, dominance, and structural distribution within a single local sampling site.

1. Species Richness ($S$)

$$S = \sum_{i=1}^{M} \mathbb{I}(p_i > 0)$$
Technical Meaning: Absolute count of distinct taxonomic entities with sequencing depth above noise threshold $\tau$.
Ecological Value: Baseline community diversity. Depressed values flag biologically degraded or chemically stressed habitats.

2. Shannon-Wiener Diversity Index ($H'$)

$$H' = -\sum_{i=1}^{S} p_i \ln(p_i)$$
Technical Meaning: Information entropy quantifying uncertainty in predicting the taxonomic identity of a randomly sampled read.
Interpretation: Typical environmental range: 1.5 to 3.5. Values > 3.0 indicate balanced, complex communities; values < 1.5 reveal severe monoculture skew or ecosystem stress.

3. Simpson’s Dominance ($D$) & Gini-Simpson Index ($1 - D$)

$$\text{Simpson's Index: } D = \sum_{i=1}^{S} p_i^2 \qquad \big|\qquad \text{Gini-Simpson: } 1 - D = 1 - \sum_{i=1}^{S} p_i^2$$
Technical Meaning: $D$ is the probability that two randomly drawn reads belong to the same species; $1-D$ is the probability they belong to different species.
Ecological Value: $D \to 1.0$ indicates strong monoculture/invasive domination. $1-D \to 1.0$ indicates a highly equitable community structure.

4. Pielou’s Evenness Index ($J'$)

$$J' = \frac{H'}{\ln(S)} \quad \text{for } S > 1$$
Technical Meaning: Normalizes Shannon entropy against theoretical maximum diversity $H'_{\max} = \ln(S)$. Bounded on $[0, 1]$.
Interpretation: $J' \approx 1.0$ reflects equal abundance among all taxa. $J' < 0.5$ signals severe population asymmetry.

Phase 3: Beta-Diversity (Cross-Sample Dissimilarity)

Beta diversity measures compositional turnover between distinct spatial sites or temporal monitoring epochs (Sample $j$ vs. Sample $k$).

1. Bray-Curtis Dissimilarity ($BC_{jk}$)

$$BC_{jk} = \frac{\sum_{i=1}^{S} |n_{ij} - n_{ik}|}{\sum_{i=1}^{S} (n_{ij} + n_{ik})}$$
Technical Meaning: Abundance-weighted compositional dissimilarity bounded on $[0.0, 1.0]$.
Interpretation: $BC_{jk} = 0.0$ signifies identical community structures; $BC_{jk} = 1.0$ signifies zero shared species.

2. Jaccard Dissimilarity ($J_{\text{dissim}}$)

$$J_{\text{dissim}} = \frac{b + c}{a + b + c}$$
  • $a$: Count of shared species present in both samples.
  • $b$: Count of species unique to Sample $j$.
  • $c$: Count of species unique to Sample $k$.
  • Presence/absence metric measuring turnover independent of PCR amplification amplification bias.

Phase 4: ML Classifier Reliability & Novelty Metrics

Assesses classifier calibration quality and evaluates how safely the model handles unseen evolutionary clades.

1. Expected Calibration Error (ECE)

$$\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{N_{\text{eval}}} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$
  • Partition confidence $[0, 1]$ into $M$ bins $B_1, \ldots, B_M$.
  • $|B_m|$: Count of predictions in bin $B_m$; $N_{\text{eval}}$: Total evaluated sequences.
  • $\text{acc}(B_m), \text{conf}(B_m)$: Empirical accuracy and mean confidence of bin $B_m$.
  • Target Objective: $\text{ECE} < 0.05$.

2. Over-Classification Error Rate ($E_{\text{over}}$)

$$E_{\text{over}} = \frac{\sum_{i=1}^{N_{\text{novel}}} \mathbb{I}(\hat{y}_i \in \mathcal{Y}_{\text{known}})}{N_{\text{novel}}}$$
  • $N_{\text{novel}}$: Count of test sequences belonging to withheld novel clades.
  • $\mathcal{Y}_{\text{known}}$: Set of known reference species in training database.
  • $\hat{y}_i$: Predicted label for query sequence $i$.
  • Target Objective: $E_{\text{over}} \to 0.0$ by halting predictions gracefully at genus/family ancestral ranks when evaluating novel taxa.
